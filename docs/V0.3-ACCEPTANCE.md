# v0.3 — First spatial authoring loop

Approved 2026-10-02 after the v0.3 discussion. Real-sample upload development and asset acquisition are deferred until the owner's evening discussion.

## Scope and plan
1. Freeze exact legacy WAV hashes; retain schema 1 / engine 0.1 rendering unchanged. Add explicitly versioned schema 2 / engine 0.3 spatial authoring and an undoable opt-in upgrade for old projects.
2. Add owned per-layer early reflections and damped diffuse late reverb. Dry synthesis remains identical; no shared room bus alters unrelated layers. Expose reflection amount, tail amount, spacing, decay, damping and predelay.
3. Extend the existing validated AI operation vocabulary and metadata context. No audio to provider, no arbitrary DSP, and no silent legacy upgrade.
4. Add separate dry/early/late audition, room controls, reference level matching (audition only), and clear export selection. Preserve current conversation/timeline layout.
5. Produce controlled before/after garage examples and metal/sci-fi regression artifacts. Verify automated DSP/contract invariants, persisted roundtrips, browser edits/undo/solo/export and responsive layout. Real AI uses existing dedicated key and existing cumulative $5 ledger; no fresh budget.

## Acceptance
- Old saved projects render to pre-change WAV hashes exactly; spatial bypass is identical after explicit upgrade.
- Reflection and tail signals are causal, finite, deterministic and bounded; longer decay produces a longer measured tail; silence stays silent.
- Room-only edits preserve dry PCM and untouched layer PCM. Lock/scope/stale/undo protection still applies.
- Three sequential room edits via real provider preserve source identity and protected content.
- Manual room edits and isolated audition work in browser; exports are labeled and do not silently follow audition state.
- Download completion in a normal browser is a distinct gate from file artifact checks. Listening/realism remains owner acceptance, never inferred from tests.
- Deliver project, dry/room comparison WAVs, screenshots and a concise results record. Google Drive private file delivery is authorized when the owner is away; no product-level cloud upload integration.

## Excluded and stopping condition
No external sound acquisition, sample-upload expansion, full node graph, model training, convolution assets, physical simulation guarantee, new dependencies, changes to other Lyra repos, Git actions or deployment. Stop once this bounded loop and its evidence are ready for owner listening; do not expand to fix unrelated issues.
